Setup

These stay in this browser only — needed to talk to your Netlify functions and to the Gemini API.

This key uses Google's free tier (rate-limited, but $0). It's sent directly from this browser to Google when generating a draft, never touching your Netlify functions. Don't share this page's URL with anyone once you've entered it, since the key lives in this browser's local storage.

Connected accounts

Threads doesn't allow a static file to do the login handshake (that step needs a secret key). So: get a long-lived access token once per account using the one-time command in the README, then paste it here.
